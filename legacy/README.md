# Legacy code (not built)

These files are the original RudraCore sources. They were adapted from the
Hjert kernel of [skiftOS](https://github.com/skift-org/skift) (MIT License,
© the skift authors) and depend on skift libraries that are not part of this
repository.

They are kept here for reference only. The new, from-scratch kernel lives in
`kernel/`. If any of this code is reused, the skift MIT copyright notice must
be kept with it.
